# Dependencies

## Runtime Dependencies

| Package | Category | Purpose |
| --- | --- | --- |
| `react` | UI | Core component library. |
| `react-dom` | UI | Renders React into the browser DOM. |
| `react-router-dom` | Routing | Client-side routes and links. |
| `framer-motion` | Animation | Route transitions and modal animation support. |
| `gsap` | Animation | Scroll-triggered and section-level animations. |
| `lenis` | Scrolling | Smooth scrolling behavior. |
| `lucide-react` | Icons | Icon components used in buttons, links, and UI controls. |

## Development And Build Dependencies

| Package | Purpose |
| --- | --- |
| `vite` | Development server and production bundler. |
| `@vitejs/plugin-react` | React support for Vite. |
| `typescript` | Type checking and TypeScript compilation. |
| `tailwindcss` | Utility CSS framework. |
| `postcss` | CSS transformation pipeline. |
| `autoprefixer` | Adds vendor prefixes through PostCSS. |
| `@types/react` | React TypeScript definitions. |
| `@types/react-dom` | React DOM TypeScript definitions. |
| `@types/node` | Node.js TypeScript definitions used by tooling. |

## Not Present

The current dependency list does not include a backend framework, database client, form service SDK, authentication SDK, state management library, test runner, or HTTP client such as Axios.
