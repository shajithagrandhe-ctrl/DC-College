DC College reference media
==========================

Place this entire folder inside the project root as:

DC_college-main/reference-media/

This is INPUT/REFERENCE media for Codex. Do not serve files directly from
reference-media. The Codex prompt will copy only the selected assets into the
existing public asset structure and update only media references where needed.

Folders:
- home
- courses
- admission
- placements
- life-at-dc
- about
- contact
- shared-video/dc-college-hero.mp4

No layout, text, feature, backend, or styling changes are part of this media pass.
